## 你的定價(單台 Mac mini,上限 2 個併發 runner)

| 方案 | 內容 | 月費建議 |
|---|---|---|
| CI Runner 單併發 | 1 個 ephemeral macOS runner,分鐘數吃到飽 | **US$60–80** |
| CI Runner 雙併發 | 整台機器 2 個併發 runner,獨佔 | **US$120–150** |
| 整台獨佔(遠端 Mac) | SSH/遠端桌面整台租用(不共用、不跑別人 job) | **US$100–150** |

定價邏輯:

- 對照 Cirrus US$150/runner,你收 60–80 就是「便宜一半、速度同級(M 系列裸金屬)」
- 對照 GitHub 託管,月燒 1,000 分鐘以上的團隊立刻省錢,而且快 2–3 倍
- **不要低於 US$50/月**——低價吸引到的是最麻煩的客戶,而且你只有一台機器,
  slot 稀缺,寧可空著等對的客戶

## 收款與條款

- 收款:Lemon Squeezy / Gumroad 訂閱制(處理國際刷卡與發票),或台灣客戶直接轉帳+開發票
- 月繳、隨時可退,當月不退費;首月半價試用
- 合約條款底線(同 security-checklist 最後一節):
  - 盡力 99% 可用,非資料中心 SLA
  - 賠償上限 = 當月月費
  - 排定維護提前 48 小時通知
  - 禁止用途:挖礦、壓力測試/DoS、任何違法工作負載;違者立即終止不退費
- 客戶端需提供:GitHub org/repo 的 runner registration token、需要的 Xcode 版本清單

## 損益速算(單位:US$/月)

```
營收(雙併發滿租)          120–150
電費(40W × 24/7,台灣電價)    ~3
網路(分攤)                   ~10
healthchecks/雜項              ~0–5
────────────────────────────────
淨利                        ~105–135/月 ≈ NT$3,400–4,300
機器成本 NT$20,000 → 5–6 個月回本,之後為純利
```

擴張:驗證跑通一台後,每加一台 Mac mini 就是複製貼上 setup 腳本 + 多一組客戶。
3 台的規模(~US$400/月)仍在家用電力與網路輕鬆負擔範圍內。
